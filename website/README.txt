INTERACTIVE BODY STUDIO - UPDATED WEBSITE

FILES NEEDED IN models/
- female_model.glb
- male_model.glb
- current_character.glb        (created by Blender export)
- current_character.json       (created by Blender export)

HOW TO RUN
1. Open this folder in File Explorer.
2. Click the folder address bar.
3. Type: cmd
4. Press Enter.
5. Run:
   py -m http.server 8000
6. Open:
   http://localhost:8000

CUSTOM MODEL WORKFLOW
1. Personalize the model in Blender.
2. Click Export Current Character.
3. Keep the local server running.
4. On the website click My Created Model.
5. After another export, click Reload created model.
